# 📊 Dirichlet Distributions Estimation

This section aims to briefly explain its contents and the rationale of the implementations.

## 🧩 Object Class Selection

We begin by defining a set of object classes:

- These classes are labeled in the **MS COCO** dataset.
- They are detectable by **YOLO**.
- They have corresponding **3D `.glb` models** in the **AI2THOR** dataset.

➡️ This enables integration of these objects into pre-built scenes for testing **robotic object search** using YOLO within the **Habitat META simulator**.

✅ The selected object classes are listed in:  
`in_indoor_objects.json`

---

## 🔍 Exploratory Data Analysis (EDA)

We perform EDA on the **MS COCO 2017** dataset (`train` and `val` splits):

- Analyze ground-truth detections of the selected object classes.
- Group detections by class → `out_ms_coco_detections.json`
- Calculate object **scale** as:  
  `scale = bbox_area / image_area`

For each object class, we build a **B-bin histogram** of scale values with approximately equal counts. These **non-uniform ranges** are grouped per class and stored in `out_bins_per_class.json`

---

## 🧠 YOLO Detections

YOLO is applied to all relevant images:

- It may detect multiple or unrelated objects.
- Only detections with  
  `IoU(ground_truth_bbox, detected_bbox) > threshold`  
  are considered valid.

For each valid detection:

- A **score vector** is recorded.
- Grouped by:
  - Ground-truth object class `C`
  - The **scale bin** the detection falls into

This results in a rich set of score vectors for every `(C, bin)` pair.

---

## 📈 Dirichlet Distribution Estimation

Using the collected score vectors, we compute `N × B` Dirichlet distributions. These distributions will be essential in **quantifying uncertainty** in detection performance later in the project.

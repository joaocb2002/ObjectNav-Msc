# 🧪 Initial Experiments with META Habitat & YOLO

This section contains exploratory experiments and hands-on tutorials focused on integrating **META Habitat** with **YOLO** for robotic perception and simulation tasks.

You'll find:

- Early-stage analyses and prototyping
- Tools and scripts to evaluate object detection performance

These materials are a foundation for future work in robotic object search, uncertainty modeling, and simulation-based validation.
